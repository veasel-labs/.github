# Contributing to Veasel Labs

We welcome bug reports, documentation improvements, design feedback, and code
contributions. Please read the contribution guide in the repository you are
changing because build, test, and release steps vary by project.

Keep reports respectful and focused on observable behavior. Do not publish
credentials, private prompts, customer data, or unreleased vulnerabilities.

Before opening a pull request, describe the user need, the change, the checks
you ran, and any security or performance impact. For visual changes, include
desktop and mobile screenshots. Do not present planned features as supported.
