# Brand assets

`veasel-labs-avatar.png` is a pixel-art avatar created from a text-only prompt.
No upstream image was supplied as a generation input. The character uses a
russet-and-cream upright silhouette, teal scarf, and midnight background for
legibility in GitHub's circular avatar crop.

The official V mascot artwork in [vlang/v-mascot](https://github.com/vlang/v-mascot)
is licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).
That artwork is not included or used as an image input for this asset.
