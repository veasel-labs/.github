# Security policy

Please report suspected vulnerabilities privately through GitHub's private
vulnerability reporting on the affected repository. If that feature is
unavailable, contact the maintainers through the organization profile before
sharing technical details publicly.

Include affected versions, impact, and a minimal reproduction. Remove API
tokens, private prompts, personal data, and proprietary source code. The
maintainers will coordinate triage and disclosure; no response-time guarantee
is currently offered.

For ordinary bugs, use the public issue forms in the relevant repository.
