Veasel Labs builds developer tools in [V](https://vlang.io/), with a focus on
native performance, understandable behavior, and practical AI workflows.

## Projects

- **[Veasel Code](https://github.com/veasel-labs/veasel)** — an open-source,
  V-native coding assistant in active development. Follow its implementation
  status and compatibility notes before relying on features still in progress.
- **[veasel.dev](https://www.veasel.dev/)** — the project home, field guide,
  API reference, and current roadmap.

## How we work

- Reuse V's standard library and keep the native core small.
- Make provider, filesystem, process, and plugin trust boundaries explicit.
- Measure performance and document the hardware and method behind results.
- Keep docs aligned with shipped behavior; label planned capabilities clearly.
- Welcome respectful, constructive contributions from people of all backgrounds.
